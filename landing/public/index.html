FAQ

Les questions qu'on nous pose souvent.

C'est vraiment gratuit ?

Oui. Pas de compte, pas d'abonnement, pas de version « Pro » payante. Le code est open source, les mises à jour sont à vie. Si tu actives la reformulation IA, tu paies uniquement le provider (Anthropic, OpenAI ou Google) selon ta consommation — Triskell ne touche rien.

Mes données sont-elles envoyées quelque part ?

Non. L'app est 100 % offline par défaut. Tes valeurs courantes (prénom, lien site, etc.) sont stockées en local dans %APPDATA%\TriskellSalesTunnel\user_state.json. Le seul appel réseau possible : si tu actives explicitement la reformulation IA, le message est envoyé uniquement au provider que tu as choisi.

Mac et Linux ?

Pas pour le moment. L'app est packagée pour Windows 10 / 11 (PyInstaller + Inno Setup). Le code Python est portable, donc lancer python run.py depuis les sources fonctionne sur Mac et Linux. Un build officiel est dans le backlog.

Comment ça compare avec un Lemlist / Apollo / Instantly ?

C'est complémentaire, pas concurrent. Lemlist envoie des séquences à grande échelle ; Sales Tunnel rédige le bon message au cas par cas, à coller manuellement dans LinkedIn DM, WhatsApp, etc. — là où l'automatisation cassante ne marche pas.

Je peux ajouter mes propres produits / cibles ?

Oui. Bouton ✦ Nouveau sur l'écran Produit pour créer un produit personnalisé, et ✦ Nouvelle cible sur l'écran Cible pour ajouter une persona. Stockés en local, dispos pour toutes les sessions futures.

Pourquoi pas plus de canaux (cold call, SMS) ?

Le scope actuel est écrit uniquement (Email, LinkedIn, Instagram DM, WhatsApp, Facebook Messenger, Twitter/X DM). Le SMS pro et les scripts cold call sont une catégorie à part qui mérite son propre outil. C'est dans le BACKLOG.
